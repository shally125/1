# Why we are here

## My position

I do not need to compete with AI at producing code quickly. However, as a director and designer interested in XR theatre, I need enough programming knowledge to describe interactions precisely, read what generated code does, and decide whether a system supports the artistic and practical needs of a rehearsal.

## My practice

My background is in radio and television directing, with a focus on theatre. I want to develop an XR rehearsal system in which actors, directors, and designers can rehearse and perform together online or within a shared virtual space.

## Questions to explore

- What is missing from the prompt “build an XR theatre rehearsal system”?
- How would actors move, communicate, receive cues, and interact with virtual scenery?
- If AI writes the code, how can I judge whether its decisions are useful, safe, and appropriate?
- How would programming knowledge change the way I imagine theatrical space?
- Do I need to write every line myself, or do I mainly need to understand, test, and revise computational behaviour?

## Provisional argument

AI changes which programming skills I need, but it does not remove the need for programming literacy. For my XR theatre practice, learning code means learning how artistic intentions become rules, interactions, limitations, and experiences.
